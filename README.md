# Khaliji-hub Sankore

## How do I install these formulae?

`brew install khaliji-hub/sankore/<formula>`

Or `brew tap khaliji-hub/sankore` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "khaliji-hub/sankore"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
